# SignalPilot

A very simple AI stock signal MVP for testing and education.

## What it does
- Type a stock ticker and view a quick buy/hold/watch signal
- See entry, stop, and target levels
- Download the report as a CSV file
- Clean, minimal dashboard design

## Important note
This is not financial advice and should not be treated as a real trading system. It is a simple prototype for product and UX testing.

## Local run
Open `index.html` directly in the browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then open: http://localhost:8000

## Publish to GitHub Pages
1. Go to your repository settings
2. Open the Pages section
3. Select the main branch and root folder
4. Save
5. Your site will be published at a GitHub Pages URL

## Product idea
This app is meant to be the foundation for a simple subscription-based stock signal tool.
